# jay | NASA / APOD

A minimal Astronomy Picture of the Day website powered by NASA's APOD API.

explore a new piece of the universe every day, with the image or video, title, date, and description pulled directly from NASA.

## preview

**live site:** https://venjae.github.io/nasa-apod/

## features

- daily NASA Astronomy Picture of the Day
- supports both images and video APODs
- animated typing effect for the APOD description
- displays the current date and APOD date
- minimal monochrome interface
- responsive layout
- API key stored securely using environment variables
- automatically deployed with GitHub Actions

## Tech Stack

- HTML
- CSS
- JavaScript
- Vite
- NASA APOD API
- GitHub Actions
- GitHub Pages
